🔧 TROUBLESHOOTING:
═══════════════════════════════════════════════════════════
Error: 404 Not Found
  → BOT_TOKEN salah atau belum diisi di .vars.json
  → Cek token di @BotFather

Error: Timeout saat create akun
  → Server VPN tidak bisa diakses
  → Cek koneksi SSH ke server
  → Pastikan setup.sh sudah dijalankan di server

Error: Promise timed out
  → Script di server terlalu lama
  → Cek log server: journalctl -xe

Database locked
  → Bot sudah running di background
  → Kill process: pkill -f "node app.js"

🚀 MANAGEMENT:
═══════════════════════════════════════════════════════════
# Jalankan dengan PM2 (recommended)
pm2 start app.js --name sellvpn
pm2 logs sellvpn
pm2 restart sellvpn
pm2 stop sellvpn

# Atau manual
node app.js
# Ctrl+C untuk stop

# Background process
nohup node app.js > bot.log 2>&1 &

# Lihat log
tail -f bot.log
